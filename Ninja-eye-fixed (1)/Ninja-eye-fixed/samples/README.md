NINJA EYE - Sample Files

This directory is for test images you want to analyze.
How to add samples:

    Copy any JPG or PNG image into this folder.
    Use the Image Metadata Analyzer to inspect it.

Recommended test images:

    A photo taken with a smartphone (has EXIF + possibly GPS)
    A screenshot (usually has no EXIF)
    A downloaded internet image (metadata varies)

Note:

Never commit personal photos with GPS data to a public repository.
